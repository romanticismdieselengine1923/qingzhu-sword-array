## 🎯 遊戲特色詳解

### 禦劍戰鬥系統
遊戲的核心玩法是操控飛劍攻擊敵人。您需要掌握飛劍的飛行軌跡，在合適的時機發動攻擊。每個敵人都有不同的弱點和攻擊模式，需要策略性地應對。

### 虛天殿探險
遊戲分為多個章節，每個章節都有獨特的場景設計和 Boss 戰。您需要擊敗鎮守各層的守護者，逐步深入虛天殿的核心。

### 角色成長
通過擊敗敵人獲得經驗值，提升角色等級。升級後可以學習新的禦劍技能，大幅增強戰鬥力。

### 收集與解鎖
遊戲中隱藏著特殊的寶箱和秘密區域，探索它們可以獲得稀有裝備和道具，豐富您的遊戲體驗。
